屏幕准星

准星是一块独立的分层小窗，画在选中显示器的正中央。它永远点击穿透、不抢焦点， 所以游戏里既不会挡住鼠标，也不会影响帧数。下面的改动都即时生效。

热键

点输入框后直接按下想用的组合键即可录入；按 Esc 取消。 支持字母、数字、F1~F24，可搭配 Ctrl / Alt / Shift / Win。

性能

「界面主题」只影响这个主窗口，悬浮窗配色在「位置与外观」里单独设置。
「程序优先级」调高可以让采集线程更及时处理事件，代价是多占一点 CPU 时间片，通常选「正常」即可。 不提供「实时」—— 那会把鼠标键盘的输入响应也挤掉。
